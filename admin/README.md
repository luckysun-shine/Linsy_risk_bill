# 林氏风险账单 · 管理后台

独立于 H5 账单客户端（`frontend/`）的运营配置端。  
与仓库根目录文档同步日期：2026-09-15。

## 能力

1. 管理员登录 / 修改密码 / 账号管理（创建、停用、重置密码、删除）  
2. 创建年度配置，载入全量默认模板（与 H5 Mock 对齐）  
3. **Excel 主路径填报**：下载多 Sheet 模板 → 上传预览变更 → 写入表单  
4. **按 H5 分屏侧边导航微调**：封面 / 风险分类 / 整改概况 / 合规数读 / 阻击战 / 重大风险 / 分类宣导…  
5. 维护部门列表，一键发布：按部门生成独立浏览链接  
6. **访问统计**：查看各已发布链接的打开次数、趋势与最近访问  

## 页面路由

| 路径 | 说明 |
|------|------|
| `/login` | 登录 |
| `/` | 年度配置列表 |
| `/campaigns/:id` | 编辑配置（Excel + 分屏编辑 + 部门 + 发布） |
| `/stats` | 访问统计 |
| `/users` | 管理员账号管理 |

## 启动

先确保后端 API 已启动（默认 `http://localhost:3000`），并完成数据库迁移：

```bash
cd backend
npm run migrate
npm run seed
npm run dev
```

再启动管理后台：

```bash
cd admin
npm install
npm run dev
```

访问：http://localhost:5180  

默认账号（seed 后）：`admin` / `admin123456`

## Excel Sheet 一览

| Sheet | 内容 |
|-------|------|
| 公司公共 | 公司名、封面、摘要指标、整改警示等 |
| 部门列表 | 编码 / 名称 / 接收人 / 是否聚焦 / 角色 |
| 部门聚焦 | 审计 / 监察 / 内控指标（`[[高亮]]`） |
| 风险分类 / 整改分类 | 名称、占比、颜色 |
| 整改概况年 / 整改概况史 | 部门整改表 |
| 合规数读 | 宣教条目 |
| 高风险阻击战 | 三部战绩 |
| 重大风险 | 上报与点赞文案 |
| 填写说明 | 操作指引 |

高亮语法：文案中写 `[[关键词或数字]]`，导入后转为 `MetricPart.accent`。

## 推荐配置流程

1. 打开年度配置 → **下载 Excel 模板**  
2. 按 Sheet 填报（公司公共、风险分类、整改概况、合规数读、部门列表、部门聚焦等）  
3. **上传表格** → 确认导入预览 → 写入表单  
4. 左侧按分屏微调文案（高亮用 `[[数字]]`）  
5. **保存并发布部门链接** → 复制发给各部门主管  

## 发布逻辑

- 统一内容保存在 `bill_campaigns.base_payload`  
- 各部门可有 `overrides` 差异字段  
- 发布时：`deepMerge(base, overrides)` → 写入 `bill_data`，并生成/更新 `bill_links`  
- 链接员工号约定：`DEPT_{YEAR}_{DEPT_CODE}`  
- H5 打开：`{BASE_URL}/bill/{year}?token=...`（`BASE_URL` 来自后端环境变量）
